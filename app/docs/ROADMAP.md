# Roadmap

O roadmap registra evolução de produto sem prometer datas. Itens concluídos
permanecem aqui para mostrar a trajetória técnica do FocusFlow.

## Entregue

- [x] Web responsiva e PWA instalável
- [x] Projetos, subtarefas, cronômetro e lançamentos manuais
- [x] Métricas de 7 e 30 dias e exportação CSV/JSON
- [x] Concorrência otimista com revisões
- [x] Dados isolados por identidade autenticada
- [x] Clientes Windows, Linux e Android
- [x] Atualização segura com validação SHA-256
- [x] Docker, Nginx, CI e varredura de segredos
- [x] Modo demonstração temporário com dados fictícios
